# Audit SEO Gratuit

Micro-aplicatie PHP NovaWeb pentru audit SEO on-page, raport public in preview, unlock prin email/contact si PDF dupa deblocare.

Documentatia canonica pentru orice LLM sau developer care trebuie sa inteleaga aplicatia fara acces la cod este:

- [docs/LLM_APPLICATION_CONTEXT.md](docs/LLM_APPLICATION_CONTEXT.md)

Comanda locala recomandata:

```powershell
php -S 127.0.0.1:8080 -t . router.local.php
```

Smoke test minim:

```powershell
php tools/check-consistency.php
```
